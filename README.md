# ChatFlare

Welcome to ChatFlare, a modern and lightweight text chat application built with React, Vite, and Firebase. ChatFlare provides real-time messaging capabilities with a clean and responsive user interface, ensuring seamless communication across devices.


### Screenshot

![](./screenshot.jpg)

### Features
- Real-Time Messaging: Chat with your friends and groups in real-time.
- User Authentication: Secure login and sign-up with Firebase Authentication.
- Cloud Storage: Store and retrieve chat data securely using Firebase Firestore.
- Responsive Design: Enjoy a consistent experience on desktop, tablet, and mobile devices.
- Fast & Lightweight: Built with Vite for a blazing-fast development and user experience.
- Easy Deployment: Ready to be deployed on various hosting services.


### Technologies used

- React: A popular JavaScript library for building user interfaces.
- Vite: A modern build tool that offers fast bundling and hot module replacement.
- Firebase: A platform for developing mobile and web applications, providing real-time database, authentication, and hosting services.
